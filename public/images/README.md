# Hero Background Image

Please add your hero background image here with the name:

**`hero-background.jpg`**

or

**`hero-background.png`**

## Recommended Specifications:
- **Format:** JPG, PNG, or WebP
- **Dimensions:** 1920x1080px or higher (16:9 aspect ratio)
- **File Size:** Optimized for web (under 500KB recommended)
- **Content:** Diverse group of happy students/learners (similar to the design mockup)

## Current Implementation:
The hero section uses: `/images/hero-background.jpg`

The image will be displayed with:
- Full width/height coverage
- Light white gradient overlay for text readability
- Clean, modern design matching the "Find Your Tribe, Build Your Network" theme

---

**Note:** If you want to use a different filename or format, update the `src` attribute in `src/App.tsx` (search for `/images/hero-background.jpg`)
